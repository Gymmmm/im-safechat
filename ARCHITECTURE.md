## 🔄 数据流

### 用户登录流程
```
┌──────┐   POST /api/auth/login   ┌─────────┐
│ 用户 │ ─────────────────────────>│  后端   │
└──────┘                           └────┬────┘
   ▲                                    │
   │                                    ▼
   │                              ┌─────────┐
   │        JWT Token             │  MySQL  │
   └──────────────────────────────┤ 验证密码 │
                                  └─────────┘
```

### 实时消息流程
```
┌────────┐                    ┌──────────────┐
│ 发送者 │ ─── WebSocket ────>│ Socket.io    │
└────────┘                    │   Server     │
                              └──────┬───────┘
                                     │
                              ┌──────▼───────┐
                              │   存储到      │
                              │   MySQL      │
                              └──────┬───────┘
                                     │
                              ┌──────▼───────┐
┌────────┐                    │ Socket.io    │
│ 接收者 │ <─── WebSocket ────│   Server     │
└────────┘                    └──────────────┘
```

### 文件上传流程
```
┌────────┐   POST /upload    ┌──────────┐
│ 用户   │ ───────────────────>│  Multer  │
└────────┘   FormData         └────┬─────┘

                                   │
                              ┌────▼─────┐

                              └────┬─────┘
                                   │
┌────────┐                    ┌────▼─────┐
│ 用户   │ <─── 返回URL ──────│  后端    │
└────────┘                    └──────────┘
```

## 📡 API 端点

### REST API
```
POST   /api/auth/register      # 注册
POST   /api/auth/login         # 登录
GET    /api/auth/all           # 获取用户列表

GET    /api/messages/:userId   # 获取消息历史
POST   /api/messages/recall    # 撤回消息

GET    /api/groups             # 获取群组列表
POST   /api/groups             # 创建群组

POST   /upload                 # 上传文件

GET    /health                 # 健康检查
```

### WebSocket Events
```
连接认证:
  auth: { token }

发送消息:
  emit('private_message', { toUserId, content, type })
  emit('group_message', { groupId, content })

接收消息:
  on('private_message', callback)
  on('group_message', callback)

群组管理:
  emit('join_group', groupId)
```
